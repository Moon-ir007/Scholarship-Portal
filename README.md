# 🎓 Scholarship Eligibility Test Portal

A lightweight, interactive web application that allows students to check their scholarship eligibility instantly. Built using **HTML**, **CSS**, and **PyScript**, this portal runs Python logic directly inside the web browser without requiring any backend server (Flask/Django) setup!

---

## 🚀 Features

*   **Client-Side Python Execution:** Powered by PyScript, meaning all scholarship evaluation rules, conditional logic, and score calculations are handled by native Python scripts right in the browser.
*   **Responsive Modern UI:** Clean, accessible, and mobile-friendly design styled with pure CSS.
*   **Instant Results:** Dynamic feedback that evaluates academic GPA, family income, and other criteria instantly upon submission.
*   **No Backend Required:** Runs entirely as a static web page—just open and run!

---

## 🛠️ Tech Stack

*   **Frontend:** HTML5, CSS3 (Flexbox, Grid, custom styling)
*   **Logic Engine:** Python
